# 技术设计

这份文档讲路由追踪为什么这样做，以及实际测过的结论。

## 为什么网页里做不了逐跳追踪

traceroute 要做两件事：设置 TTL，接收 ICMP「超时」回包。网页两件都做不到：

- `fetch`、WebSocket、WebRTC 都不能设 TTL。
- 浏览器收不到 ICMP。

开着代理时，就算在本机跑 `tracert`，看到的也只是代理的虚拟网关（如 `198.18.0.1`）加一串 `*`。所以逐跳数据只能来自一台真正发包的机器。这里用的是 [Globalping](https://globalping.io) 的探针：全球几千个，分布在家宽和机房里，接口支持浏览器跨域调用。

## 测量

- 每次只用一个探针跑一次 MTR，每跳 5 到 16 个包。
- 免费额度按 IP 每小时 250 次，一次追踪用 1 次。剩余次数来自响应头 `x-ratelimit-*`，页面会显示出来。
- 自动选中的探针可能已经下线（接口返回 422）。这时页面换下一个最匹配的探针，最多试 3 次。

## 探针匹配

- **去程**：探针和访客的网络越像越好。排序依次是：同 AS，同运营商集团（大陆三家按集团归并），同城，离得近。
  - 运营商之间的差别远大于城市之间：各家有各自的骨干网和国际出口。所以「同运营商、不同城市」排在「同城、不同运营商」前面。
- **回程**：探针选在目标附近，以距离为主；同一网络只有在 1500 km 以内才加分。否则同 AS 的权重会压过距离，比如给纽伦堡的目标挑到洛杉矶的探针。
  - 测过去程的话，用去程终点的位置。任播地址在地理数据库里只到国家，位置靠不住。
- **访客的网络**：和 1ms.dog 首页用同一组检测：`/_ms/me`、ipip.net、Cloudflare、ip.sb、ipinfo、只有 IPv4 或只有 IPv6 的主机、STUN。结果按 AS 分组，机房网络标成代理出口。
- **回程目标**：默认填本机线路的地址。输入框列出检测到的所有地址，也接受任意 IP 或域名。
- **IPv4/IPv6 选项**：只在目标是域名时出现。目标是 IP 时版本已经确定，Globalping 也不接受这个参数。

## 跳点分析（`src/lib.mjs`）

- **延迟**：每一跳取它自己和后面所有跳里最低的往返时间。路由器回应探测包排在最后、经常偏慢，而发给后面跳的包一定经过了这一跳。
- **丢包**：只有一直持续到终点的才算。某一跳不回、后面各跳正常，只说明那台路由器忙。
- **探针自己的局域网**：第一个公网跳之前的私网和 CGNAT 跳不计。
- **位置要和延迟对得上**：光在光纤里每毫秒往返大约走 100 km。
  - 离探针比往返时间允许的还远，这个位置就不画。
  - 延迟不到 3 ms 的跳，放在探针所在的城市。
  - 来自登记信息的位置，如果和前后跳对不上，就去掉。
- **跳变解释**：延迟涨得最多的那一段，用两种情况解释：
  - 往返时间正好够到后面路径上某个远处地点，说明流量被送去了那里；
  - 路径在这里进入另一个国家。
- **线路命名**：按网段、AS、主机名和组织名识别中国电信 CN2、163、CTG，中国联通 169、9929、CUG，中国移动 CMNET、CMI、CMIN2，以及交换中心、大的转接网和云厂商。

## 跳点地理位置：来源和测过的结论

现在用的，都免费且有 CORS：

| 来源 | 用在哪 |
|---|---|
| PeeringDB（`netixlan`、`ix`、`net`） | 交换中心端口上的跳，准 |
| 路由器主机名里的 IATA 和 CLLI 代码 | 主机名带地点的跳 |
| GeoJS 批量查询，只到国家的再用 ipinfo 细化 | 其余的跳 |
| RDAP（rdap.org） | 没人在 BGP 里宣告的地址是谁注册的 |

没人宣告的地址，地理数据库给的城市只是网段的登记地。比如中国联通国际（CUG）的链路地址都登记在香港。这类位置显示时加问号，地图上画成空心点和虚线。GeoJS 对这类地址返回 AS 64512，代码会丢掉这个值。

试过但不用的：

| 来源 | 结论 |
|---|---|
| RIPE IPmap | 跨域能用，但没有中国骨干网的数据 |
| NextTrace / LeoMoe 的地理 API | 不能用，验证过 |
| 用 Globalping 从几个候选城市 ping 同一跳来定位 | 大多数探针收不到回包，得不出结论 |
| 其他免费数据库（ip.sb、ip.guide、ipapi.is、CZ88 等） | 对 CUG 一类没宣告的链路地址，给的同样是登记地 |

## 隐私

- 所有请求从访客浏览器直接发给上面这些公共服务。Worker 只负责给 `/r/<码>` 分享链接生成预览标题和描述，不参与测量。
- 分享链接把各跳和位置压缩进网址（`src/code.mjs`），Globalping 的结果过期后照样能打开。
- 回程目标多半是访客自己的地址，所以分享时默认打码：IP 只留前半段，域名去掉第一段，域名解析出的地址也一起打码。访客在分享框里勾选后，才完整显示。
