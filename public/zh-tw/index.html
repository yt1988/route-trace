測的是誰的網路？

Globalping 在全球有幾千個探針，裝在別人的家用網路和機房裡。去程從一個和你同業者、盡量同城的探針出發，看你這類網路去目標怎麼走；回程從目標附近的探針出發，追蹤回你的 IP。探針自己的區域網路不計入路徑。

為什麼自動選的探針不在我的城市？

Globalping 在很多城市沒有和你同業者的探針。業者之間的線路差別比城市之間大得多，所以同業者的外地探針排在同城的其他業者前面。點探針可以自己換。

帶問號的城市是什麼意思？

有些骨幹網位址在路由表裡沒人宣告，地理資料庫只知道它登記在哪裡，例如中國聯通國際的位址都登記在香港。這種位置會加一個問號，用虛線畫在地圖上；如果它和前後兩跳的延遲對不上（光在光纖裡每毫秒往返約 100 公里），就不畫。

請求送到了哪裡？

全部從你的瀏覽器直接送出，不經過 1ms.dog 的伺服器：Globalping（探針和測量，目標和回程時你的 IP 會交給它，結果憑測量 ID 公開可查），ipip.net、Cloudflare、ip.sb、ipinfo、GeoJS（辨識出口 IP 和定位每一跳），PeeringDB（交換中心），RDAP（位址的登記資訊），以及公共 STUN 伺服器。

為什麼某一跳掉包很多，路徑卻算沒掉包？

路由器回應探測封包的優先順序很低，常常不回。某一跳掉包、後面的跳都正常，就只是它沒空回，不是真的掉包；一直延續到終點的掉包才算。

額度怎麼算？

Globalping 依連到它的 IP 計算，每小時 250 次，每次追蹤用 1 次。開著代理時依代理出口計算，同一個出口的人共用。
