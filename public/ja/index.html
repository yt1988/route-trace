誰の回線を測っているのですか？

Globalping は世界中の家庭回線やデータセンターに数千台のプローブを置いています。往路は、あなたと同じ事業者で、できれば同じ都市のプローブから出発し、あなたのような回線が宛先までどう届くかを示します。復路は宛先の近くのプローブから出発し、あなたの IP まで追います。プローブ自身の LAN は経路に数えません。

おすすめのプローブが自分の都市にないのはなぜ？

多くの都市には、あなたと同じ事業者のプローブがありません。事業者ごとの違い（バックボーンや国際回線）は都市の違いよりずっと大きいので、同じ事業者の別の都市のプローブを、同じ都市の別の事業者より上に並べています。プローブをタップすれば自分で選べます。

都市名の「?」は何ですか？

一部のバックボーンのアドレスはルーティングテーブルに載っておらず、データベースは登録地しか知りません（たとえば中国聯通国際のアドレスは香港で登録されています）。そうした場所には「?」を付け、地図では破線で描きます。前後のホップとの遅延と合わない場合（光ファイバーは往復 1 ミリ秒あたり約 100 km）は描きません。

リクエストはどこへ送られますか？

すべてあなたのブラウザから直接送られ、1ms.dog のサーバーは通りません。送り先は Globalping（プローブと測定。宛先と、復路ではあなたの IP を受け取り、結果は測定 ID で公開されます）、ipip.net・Cloudflare・ip.sb・ipinfo・GeoJS（出口 IP と各ホップの位置）、PeeringDB（IX）、RDAP（アドレスの登録情報）、公開 STUN サーバーです。

途中のホップにロスがあるのに、経路はロスなしなのはなぜ？

ルーターは測定パケットへの応答を後回しにし、よく返事をしません。あるホップで応答が欠けても、その先のホップがすべて正常なら、そのルーターが忙しかっただけです。終点まで続くロスだけが本当のロスです。

利用枠はどう数えますか？

Globalping は接続元の IP ごとに 1 時間 250 回まで、1 回のトレースで 1 回分です。プロキシ経由ならプロキシの出口で数えるので、同じ出口の人と共有になります。
